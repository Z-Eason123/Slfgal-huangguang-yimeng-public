本指南写给第一次安装这类游戏的人，覆盖从下载、安装到启动的全部过程；请先找到与你设备对应的部分，再按编号逐步进行；遇到问题时，请优先对照本指南对应步骤与常见问题

游戏与文件信息
版本号：1.0.3
安卓版：huangliangyimeng-1.0.3.apk，约 118MB，支持 Android 5.0 及以上（鸿蒙 NEXT 除外）

--- 对于安卓安装用户 ---

注意：鸿蒙 NEXT（鸿蒙 5）不支持安装 APK

1. 下载网盘中的 APK 游戏文件。文件约 118MB，若下载到的文件明显小于此，说明下载不完整，请重新下载
2. 双击 APK 文件进入安装界面。若系统提示不允许安装未知应用：设置 → 安全与隐私 → 安装未知应用 → 找到你用来打开文件的应用（文件管理/浏览器/网盘 App）→ 允许。出现这一提示是因为系统只信任应用商店来源，本游戏不经商店分发，因此会被统一拦下，并非游戏本身有问题
3. 安装过程中弹出「安全守护」类检测提示，这类检测是各厂商对非商店分发应用的统一警告，请对照你的机型继续：
   OPPO「安全守护」：点弹窗右上角图标关闭，或在安装页点「授权本次安装」并输锁屏密码
   小米「高危应用」警告：点「继续安装」；若要求验证账号 → 安装页右上角齿轮 → 应用安全验证 → 改用锁屏密码
   华为「应用检测」：点「了解风险」→「仍然安装」；若装后被判定风险 → 手机管家 → 应用管控中心 → 解除管控
   vivo：等待检测完成后点「安装」
4. 安装完成后，桌面上应出现游戏图标
5. 首次打开请允许存储权限，存档与设置需要写入设备。请调整系统音量、游戏内背景音乐与角色配音音量至合适。点击屏幕推进对话

--- 对于 Windows 电脑用户 ---

注意：请勿使用网盘在线解压！请勿使用网盘在线解压！！请勿使用网盘在线解压！！！

1. 下载网盘中的 ZIP 游戏文件。文件约 109MB，若下载到的文件明显小于此，说明下载不完整，请重新下载
2. 找到游戏下载的目录位置：
   浏览器下载：此电脑 → 「下载」文件夹
   百度网盘客户端：默认在 D:\BaiduNetdiskDownload；或在客户端「传输」→「下载」页，右键文件 →「打开下载目录」
   夸克客户端：默认在 C:\Users\用户名\Quark\Downloads（"用户名"为你自己的登录名）；或在客户端「传输」列表，点击下载任务的文件夹图标直接跳转到所在目录
3. 在本地目录选用解压缩工具（如 7-Zip 或 WinRAR）进行解压：先在网盘下载目录里新建一个文件夹，命名为 huangliang（纯英文），右键 ZIP 文件 →「解压到指定文件夹」→ 选中新建的 huangliang 文件夹。解压完成后，huangliang 文件夹内应能看到 SLFGgal.exe
4. 将整个游戏文件夹移至纯英文路径，如 D:\games\（如果没有可以新建）。部分系统对含中文的路径支持不佳，可能导致无法启动；不建议放置于 Program Files，请勿放置在 OneDrive 或网盘同步文件夹
5. 启动：双击游戏文件夹内的 SLFGgal.exe
6. 安装成功后，ZIP 文件可以删除

--- 对于 mac 电脑用户 ---

1. 下载网盘中的 ZIP 游戏文件。文件约 104MB，若下载到的文件明显小于此，说明下载不完整，请重新下载
2. 双击 ZIP 文件进行解压，macOS 自带解压能力。解压完成后，应出现 SLFGgal.app
3. 将 SLFGgal.app 移入「应用程序」文件夹，或任意纯英文路径的文件夹
4. 首次打开：若双击后提示"SLFGgal 无法打开，因为它来自身份不明的开发者"，请右键（或双指点击）SLFGgal.app →「打开」→ 在弹窗中点「打开」。这是 macOS 对未经 App Store 分发的程序的统一提示，并非游戏本身有问题；此后即可正常双击打开
5. 安装成功后，ZIP 文件可以删除

--- 游戏内快速上手 ---

左键点击推进对话。请通过「设置」调整主音量、音乐与角色配音音量至合适

--- 常见问题 ---

提示「应用未安装」→ 文件未下载完整，或之前装过旧版本 → 重新下载，或先卸载旧版本
双击 exe 没有反应 → 双击的是在 ZIP 下的exe而非解压后的 exe；路径含中文；
文件被杀毒软件隔离 → 请确认运行的是解压文件夹内的 exe，将文件夹移至纯英文路径，查看杀毒软件隔离区并恢复、加入信任区；必要时右键 exe →「以管理员身份运行」
游戏没有声音 → 系统音量被关闭，或游戏内音量过低 → 请先调整系统音量，再在游戏「设置」中调整主音量、音乐与角色配音音量至合适

--- 更新与存档 ---

新版本将通过原下载渠道与 GitHub Releases 发布
安卓：直接安装新 APK 覆盖旧版本，存档不会丢失；卸载游戏会清除存档
电脑：存档位于游戏文件夹内的 saves 文件夹；更换新版本时，请先复制旧游戏文件夹内的 saves 文件夹，解压新版本后再放回新游戏文件夹；删除游戏文件夹会清除存档
mac：存档保存在应用内部；更换新版本时，请先取出旧应用的存档（右键 SLFGgal.app →「显示包内容」→ Contents/Resources/autorun/saves），再放回新应用的同一位置；删除应用会清除存档
